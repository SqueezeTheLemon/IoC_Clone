# IoC 컨테이너 클론 v3 — @Configuration·@Bean

## 1. 라이브러리 안의 코드도 빈으로 사용하고 싶다면?
라이브러리는 내가 수정할 수 없는 code -> 따로 그 위에 @Component 배지를 추가할 수 없다. 

즉, 스프링은 만드는 방법을 메소드로 적어주면
그를 대신 불러서 "결과를 빈으로 쓰겠다"는 방식. 


### 1.1 v2 vs v3

재료를 모아서 -> 호출하고 -> 결과를 창고에 넣는다는 흐름은 동일함. 

|          | v2(@Component)       | v3(@Bean)      |
|----------|----------------------|----------------|
| 배지를 다는 곳 | 클래스                  | 메소드            |
| 빈이 되는 것  | 그 클래스의 객체            | 메소드의 반환값       |
| 만드는 방법   | 생성자 호출 (newInstance) | 메소드 호출 (invoke) |
| 빈 이름     | 클래스 이름               | 메소드 이름         |
| 의존성      | 생성자 파라미터             | 메소드 파라미터       |
